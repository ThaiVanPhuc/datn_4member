2. Sequence Diagram - Dang ky va Xac thuc Email

sequenceDiagram
    autonumber
    participant U as User Browser
    participant AC as AuthController
    participant AS as AuthService
    participant US as UsersService
    participant DB as Database
    participant MS as MailService

    U->>AC: POST /auth/register
    Note right of U: {email, password, name, phone}
    AC->>AS: register(dto)
    AS->>US: findByEmail(email)
    US->>DB: user.findUnique({email})
    DB-->>US: null hoac user

    alt Email da ton tai va isActive=true
        AS-->>U: BadRequestException - Email da ton tai
    else Email chua ton tai hoac isActive=false
        AS->>AS: hashPassword(password)
        AS->>AS: generateResetCode()
        AS->>DB: user.create({...data, isActive:false})
        DB-->>AS: unverified user
        AS->>MS: sendRegistrationVerification(user, code)
        MS-->>AS: Email sent
        AS-->>U: {user, message: Ma xac thuc da gui}
    end

    Note over U,MS: === Xac thuc Email ===

    U->>AC: POST /auth/verify-registration
    Note right of U: {email, code}
    AC->>AS: verifyRegistration(email, code)
    AS->>US: findByEmail(email)
    AS->>AS: assertValidCode(user, code)

    alt Code hop le va chua het han
        AS->>DB: user.update({isActive: true})
        DB-->>AS: activated user
        AS-->>U: {success: true, message: Xac thuc thanh cong}
    else Code khong hop le hoac het han
        AS-->>U: BadRequestException - Ma khong dung/het han
    end

3. Sequence Diagram - Quy trinh Dat hang

sequenceDiagram
    autonumber
    participant B as Buyer Browser
    participant OC as OrdersController
    participant OS as OrdersService
    participant CS as CartService
    participant DB as Database
    participant NS as NotificationsService
    participant PS as PaymentsService
    participant ST as Stripe

    B->>OC: POST /orders
    Note right of B: {items, receiverName, phone, address, paymentMethod}
    OC->>OS: create(dto, userId)
    OS->>OS: Validate receiver info

    OS->>DB: $transaction start

    loop Voi moi item trong don hang
        OS->>DB: product.findMany({id in productIds})
        OS->>DB: productVariant.findMany({id in variantIds})
        OS->>OS: Validate seller.status === APPROVED
        OS->>OS: Validate stock >= quantity
        OS->>OS: Calculate price
    end

    OS->>OS: Calculate totalAmount, shippingFee, finalAmount
    OS->>OS: generateOrderCode()
    OS->>DB: order.create({...orderData, orderItems})
    OS->>DB: payment.create({orderId, method, status: UNPAID})

    loop Cap nhat stock cho moi san pham
        OS->>DB: product.update({stock: decrement})
    end

    OS->>DB: cartItem.deleteMany({userId, productId})
    OS->>NS: createForUser - Thong bao dat hang thanh cong

    OS->>DB: $transaction commit
    OS-->>B: {success: true, order}

    alt paymentMethod === STRIPE
        B->>PS: POST /payments/stripe/checkout
        PS->>ST: checkout.sessions.create()
        ST-->>PS: {sessionId, url}
        PS-->>B: {checkoutUrl}
        B->>ST: Redirect to Stripe Checkout
        ST-->>B: Redirect to success_url
    end

4. Sequence Diagram - AI Chatbot

sequenceDiagram
    autonumber
    participant U as User Browser
    participant CC as ChatbotController
    participant CS as ChatbotService
    participant DB as Database
    participant AI as AI Memory System

    U->>CC: POST /chatbot/send
    Note right of U: {message, sessionId?}
    CC->>CS: sendMessage(message, userId, sessionId)
    CS->>CS: getOrCreateSession(userId, sessionId)

    alt Co sessionId
        CS->>DB: chatSession.findUnique({id: sessionId})
    else Khong co sessionId, user da dang nhap
        CS->>DB: chatSession.findFirst({userId}) OR create new
    end

    CS->>DB: chatMessage.create({sender: USER, message})
    CS->>CS: getConversationContext(sessionId, userId)
    CS->>DB: chatMessage.findMany({take: 10})
    CS->>DB: aiMemory.findUnique({key: chatbot_profile})

    CS->>CS: parseMessage(message, context)
    Note right of CS: detectLanguage -> vi/en
detectIntent -> greeting/product_search/...
extractProductKeyword
extractPriceMax

    CS->>CS: buildBotPayload(parsed, userId, context)

    alt Intent = product_search hoac recommendation
        CS->>DB: product.findMany({...filters, status: ACTIVE})
        CS->>CS: Score and rank products
    else Intent = order_tracking
        CS->>DB: order.findFirst({userId, orderBy: createdAt})
    else Intent = add_to_cart
        CS->>CS: resolveCartProduct(parsed, context)
    end

    CS->>DB: chatMessage.create({sender: BOT, message: response})
    CS->>CS: learnFromConversation(userId, parsed, payload)
    CS->>DB: aiMemory.upsert({key: chatbot_profile, value: preferences})

    CS-->>U: {sessionId, response, products, quickReplies, intent}

5. Sequence Diagram - Dang ky Seller va Duyet

sequenceDiagram
    autonumber
    participant B as Buyer Browser
    participant A as Admin Dashboard
    participant SC as SellersController
    participant SS as SellersService
    participant DB as Database

    Note over B,DB: === Buyer dang ky lam Seller ===

    B->>SC: POST /sellers/register
    Note right of B: {shopName, description, logo, phone, address}
    SC->>SS: register(userId, dto)
    SS->>DB: user.findUnique({id: userId, include: sellerProfile})

    alt sellerProfile.status === APPROVED
        SS-->>B: BadRequestException - Da duoc duyet
    else sellerProfile.status === PENDING
        SS-->>B: BadRequestException - Dang cho duyet
    else sellerProfile.status === SUSPENDED
        SS-->>B: ForbiddenException - Bi dinh chi
    else Chua co profile hoac REJECTED
        SS->>SS: uniqueSlug(shopSlug || shopName)
        SS->>DB: sellerProfile.upsert({...data, status: PENDING})
        SS-->>B: {success, message: Da gui dang ky, profile}
    end

    Note over B,DB: === Admin duyet ho so Seller ===

    A->>SC: GET /admin/sellers?filter=pending
    SC->>SS: findAll({filter: pending})
    SS->>DB: sellerProfile.findMany({status: PENDING})
    SS-->>A: {sellers: [...pending]}

    A->>SC: POST /admin/sellers/:id/approve
    SC->>SS: approve(id)
    SS->>DB: $transaction start
    SS->>DB: role.findUnique({name: SELLER})
    SS->>DB: user.update({roleId: sellerRoleId, accountRole: SELLER})
    SS->>DB: sellerProfile.update({status: APPROVED})
    SS->>SS: syncLegacyShop(profile)
    SS->>DB: shop.upsert({ownerId, status: active, approvedAt})
    SS->>DB: $transaction commit

    SS-->>A: {success, message: Da duyet, profile}
